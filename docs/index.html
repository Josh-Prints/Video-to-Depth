How to make the token
  1. Open github.com → New fine-grained token.
  2. Name it depth-pass. Pick an expiry.
  3. Repository access: Only select repositories → .
  4. Permissions → Repository: Contents = Read and write, Actions = Read-only.
  5. Generate, copy, paste below.
